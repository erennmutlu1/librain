# Code of Conduct

This project adopts the Contributor Covenant, version 2.1, as its Code of Conduct.
The full text is available at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

By taking part in this project (issues, pull requests, discussions) you agree to uphold it.
To report a concern, contact the maintainer at erennmutlu@outlook.com. Reports are reviewed
and handled confidentially.
